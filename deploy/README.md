# Deploying Dhwani-Kavach v2 — ₹0, no credit card

Two paths. **Primary** = Hugging Face Spaces (public https URL, always on). **Fallback**
= Cloudflare Quick Tunnel from your laptop (zero account, bulletproof for demo day). Rehearse
both once. All commands run from the repo's `backend/` directory unless noted; `PY` is the repo
venv: `c:/Users/.../Dhwani-Kavach/.venv/Scripts/python.exe`.

---

## Path A — Hugging Face Spaces (primary)

**Free CPU Basic: 2 vCPU / 16 GB RAM / 50 GB ephemeral disk, Docker SDK, https, no card.**
Note the disk is ephemeral — enrollments reset when the Space sleeps (48 h idle). That's fine:
we enroll live on stage (§ demo). 2026 forum reports show occasional free-quota flakiness — hence
Path B exists.

1. **Make a free account + token.** huggingface.co → sign up → Settings → Access Tokens →
   *New token* → type **Write** → copy it (`hf_...`).
2. **Assemble + push** (uploads ~300 MB of weights via LFS automatically):
   ```
   HF_TOKEN=hf_xxx $PY scripts/build_space.py --push YOURNAME/dhwani-kavach
   ```
   (Omit `--push` to only build the local `space/` folder and inspect it first.)
3. **Set the admin secret.** In the Space UI → Settings → *Variables and secrets* → New secret:
   `KV_ADMIN_KEY` = something long. (Optional: `KV_CM=cotrain` is already the Docker default.)
4. **Wait for the build** (Logs tab). First build runs `verify_app.warmup`, baking ECAPA +
   whisper-tiny into the image so cold start is instant. ~10–15 min.
5. **Test from a phone on mobile data** (not venue Wi-Fi): open `https://YOURNAME-dhwani-kavach.hf.space`,
   Enroll (3 clips), then Verify. Confirm the "Waking up the engine…" state appears then clears.

**Demo-day rule:** open the Space ~15 min before you present so it's warm.

---

## Path B — Cloudflare Quick Tunnel (fallback, no account)

Runs the app on your laptop and exposes a public https URL in ~5 seconds. Judges' phones hit
your machine. Nothing to sign up for.

1. **Run the app locally:**
   ```
   KV_ADMIN_KEY=picksomething $PY -m uvicorn verify_app.main:app --host 0.0.0.0 --port 8000
   ```
   Wait for `/v2/health` to report `models_loaded:true` (first run downloads ECAPA + whisper).
2. **Install cloudflared once** (Windows): `winget install --id Cloudflare.cloudflared`
   (or download the `.exe` from the Cloudflare releases page — no login).
3. **Open the tunnel:**
   ```
   cloudflared tunnel --url http://localhost:8000
   ```
   It prints a `https://<random>.trycloudflare.com` URL. Share that. Done.

Keep the laptop awake and on stable internet. Practice this end-to-end at least once.

## Pre-demo checklist

- [ ] `KV_ADMIN_KEY` set from a secret/env (never the `dev-admin-key` default).
- [ ] Enroll + verify works from a **phone on mobile data**.
- [ ] Cold-start "waking up" state shows then recovers.
- [ ] Thresholds in `verify_app/config.py` are the **Phase-7 calibrated** values, not defaults.
- [ ] Path B rehearsed as backup.
- [ ] Space opened 15 min early (Path A).

## Notes

- The `space/` folder is generated by `build_space.py` and is gitignored; regenerate anytime.
- The SLS CM (`KV_CM=sls`, 1.35 GB) is NOT baked into the image. If Phase 7 picks it, upload
  `xlsr_sls.safetensors` to a free HF *model* repo and `hf_hub_download` it inside `warmup.py`.
- Latency budget on free CPU: ~2–5 s per verification. The UI shows staged progress.
